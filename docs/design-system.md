# Agent TUI Manager 前端设计系统

本文档是 `.superpowers/brainstorm/windows-1786089989/content/` 中六个 HTML 设计稿的实现规范。设计稿是视觉来源；业务数据、Agent 状态和操作权限必须来自应用的结构化状态。没有设计稿覆盖的页面，按本文档的共性令牌与扩展原则实现。

## 1. 产品外壳与信息层级

产品是 Windows 优先的桌面工作台，不是营销页。首屏直接进入工作台；用户可以在总览、处理中心、历史会话、设置之间切换。总览同时显示约 2–6 个 Agent，点击卡片的放大按钮进入全屏主终端，返回后回到原来的总览滚动位置。

暗色工作台的标准骨架如下：

```text
54px App Bar
└─ 215/216px 工作区 Rail + 主内容区
   └─ 45/46px Section Bar + 内容（终端墙、表格或详情）
```

导航只表达位置和数量，不在侧栏堆叠多个完整页面。重要操作在当前上下文完成：低风险授权可在卡片内处理，高风险授权打开右侧详情抽屉；新增/恢复 Agent 使用右侧抽屉；单个终端详情使用全屏覆盖层或主终端布局。

`architecture-v1.html` 是架构说明页，采用独立的浅色阅读变体：背景 `#f3f5f6`，白色面板 `#ffffff`，文字 `#172126`，次要文字 `#66747b`，边框 `#d8dfe2`，绿色 `#147a5c`，蓝色 `#245f9e`，琥珀 `#9b6500`，红色 `#a23a3a`。该变体仅用于架构/文档类页面，不得带入运行中的工作台。

## 3. 字体、排版与间距

- 默认字体：`Inter, "Segoe UI", "Microsoft YaHei", sans-serif`；字距固定为 `0`，禁止负字距和按视口缩放字号。
- 工作台默认 `13px/1.45` 或 `13px/1.5`。架构页 `14px/1.5`。
- App Bar 标题约 `13–15px`，Section 标题 `13px`，卡片 Agent 名称 `10–11px`，详情标题 `19–20px`。
- 标签、状态和元数据使用 `8–10px`，并可使用 `text-transform: uppercase`；正文说明约 `10–11px`。
- 终端必须使用 `"Cascadia Mono", Consolas, monospace`，总览字号 `9–11px`，主终端 `12–13px`，行高 `1.5–1.6`。终端输出保留换行并允许长路径折行。
- 基础间距以 4/5/6/7/8/10/12/14/18/20/24px 为主。终端墙卡片间距固定 `8px`，网格内边距 `8px`。
- 文本溢出：标题和单行元数据使用省略号；命令、路径和错误消息使用 `overflow-wrap:anywhere`，不能撑破容器。

## 4. 控件规范

### 4.1 App Bar

高度固定 `54px`，水平内边距 `14px`，元素间距 `12px`。左侧品牌块 `29×29px`，边框 `#3e665a`，圆角 `5px`，绿色字母标识。标题和工作区路径两行显示，路径 `9px`、`muted`，两者都省略溢出。右侧依次放通知图标、主要操作和可选辅助操作；使用 `flex:1` spacer 将其推到右侧。

### 4.2 按钮

所有按钮最小高度 `34px`，边框 `1px solid #344145`，圆角 `6px`，背景 `#202a2d`。图标按钮固定 `34×34px`，只在图标无法自解释时提供 tooltip/title；熟悉动作优先使用图标（刷新、关闭、放大、发送、停止）。

- 普通按钮：水平内边距 `12px`，文本 `text`，用于取消、查看、规则入口。
- 主按钮：水平内边距 `13px`，背景/边框 `#4dcc99`，文字 `#062219`，字重 `900`。选中时使用 `outline: 3px solid rgba(77,204,153,.34); outline-offset:2px`。
- 危险按钮：背景 `#4a292c`，边框约 `#754045`，文字 `#ffd9d9`；只用于确认删除等不可逆动作。
- 紧凑 mini action：高度 `27–28px`，圆角 `4px`，字号 `9px`。批准按钮用浅绿色 `#65c99f–#68cda4`，拒绝/暂停使用中性或危险变体。
- 分段控制：外层 `#101719`、边框 `#344145`、圆角 `6px`、内边距 `3px`；按钮高度 `28px`，活动项背景 `#304044`。
- 输入/选择框：最小高度 `36px`，背景 `#0e1517`，边框 `#39474b`，圆角 `5px`，水平内边距 `10px`。高级字段可折叠，避免首屏暴露参数噪音。

### 4.3 状态标识

状态采用“圆点 + 文本”，圆点 `7–8px`、圆形，不只依赖颜色：

| 状态 | 颜色 | 语义 |
| --- | --- | --- |
| 运行中 | `#4dcc99` | PTY 活跃、持续输出 |
| 等待授权/低风险 | `#efbd58` | 有明确、未过期的权限请求 |
| 已完成 | `#78afe6` | 正常结束，不触发自动 Continue |
| 异常/高风险 | `#f07b7b` | 明确错误或高风险操作 |
| 恢复中 | 红色或琥珀文字 | 已确认异常，有限次重试 |

圆点应配合文本和详情，不能仅凭颜色判断状态。通知数量徽标 `17×17px`，琥珀底、深色字、顶部右侧偏移 `-5px`。

## 5. 导航、总览和终端墙

### 5.1 工作区 Rail

宽度 `215px`（布局稿 `216px`），背景 `#151d20`，右边框 `#344145`。内边距 `12–13px 10px`。分组标签 `9–10px`、颜色 `#718186/#728287`、全大写。导航项最小高度 `39px`，内边距 `0 9px`，圆角 `5px`；活动项背景 `#283438` 或 `#263235`、白字。工作区项可在右侧显示会话数，待处理数使用琥珀色。

宽度低于约 `1050/980px` 时收窄为 `72px`，隐藏文字和分组说明，仅保留图标；低于 `760/650px` 时隐藏 rail，主内容单列。

### 5.2 Section Bar

高度 `45–46px`，背景 `#192225`，底边框 `#344145`，水平内边距 `12px`。左侧显示 Agent 数量（`13px` 强调）和状态摘要（`10px` muted），右侧显示工作区/共享范围和刷新按钮。

### 5.3 Layout A：终端墙（默认）

主体为 `grid-template-columns: repeat(2, minmax(260–300px,1fr))`，两行，卡片间距 `8px`、内边距 `8px`；卡片最小高度约 `190–210px`，圆角 `7px`，边框 `#344145`。卡片内部固定头部 `39–40px`、终端主体和可选底部状态条三行布局。

Agent 头部使用 `#202a2d`；标识块 `22×22px`、圆角 `4px`（Codex 绿色、Claude 琥珀、Pi 蓝色）。放大/更多等 tile 工具 `26×26px`、无边框，hover 背景 `#344145`。终端为 `#0b1011`，默认隐藏滚动条但保留主终端完整滚动能力。

卡片状态：等待授权边框琥珀（约 `#8b682d`），危险边框红色（约 `#7c4145`）。底部授权条最小高度 `43–48px`，琥珀背景 `#30291a`、顶部边框 `#604d25`；高风险使用红色背景并仅显示“查看并处理”，打开抽屉后再确认。恢复条最小高度 `34px`，红色背景并说明“明确异常退出，正常结束不会触发”。

### 5.4 Layout B：主终端 + 会话侧栏

三列：左侧会话列表约 `276px`，中间主终端 `minmax(360px,1fr)`，右侧处理面板约 `290px`。会话项最小高度 `74px`、圆角 `6px`、间距 `7px`；活动项绿色边框和 `#20332d` 背景。中间区域三行：头部 `48px`、终端、命令栏 `38px`。命令栏输入高度 `27px`。

右侧处理面板背景 `#1a2326`，处理项约 `11px` 内边距、`6px` 圆角，危险/警告使用对应边框；“最近完成”与待处理分组展示。窄屏隐藏右侧处理面板，再隐藏会话列表，保留主终端。

### 5.5 Layout C：任务调度台

整体三行：工具栏 `52px`、Agent 表格主区、底部详情约 `240px`。工具栏包含状态分段控制和工作区/刷新。表格背景 `#182124`、边框 `#344145`；表头高度 `34px`，行高 `51px`，单元格水平内边距 `12px`，表头 `9px` uppercase。选中行背景 `#20322d`，hover `#1d292b`。

底部详情两列：左侧终端、右侧统一队列约 `360px`；窄屏改为单列并可隐藏队列。队列行顶部使用 `#2b373a` 分隔线，展示来源、目标、风险和直接动作。

### 5.6 放大终端覆盖层

覆盖层 `position: fixed; inset:0`，背景 `#0b1011`，三行 `52px 1fr 42px`。头部 `#182124`，左侧“返回总览”，右侧 Agent 标题、实时终端状态和更多菜单。底部 `#151d20`，显示工作区路径及 `ConPTY · UTF-8 · 列×行` 等事实信息。打开/关闭必须保留终端滚动位置和输入焦点，不重建 PTY。

## 6. 新增 Agent / 恢复 / 外部迁移抽屉

### 6.1 通用抽屉

使用 scrim 遮罩（`rgba(3,7,8,.56–.58)`），抽屉从右侧进入，不使用居中表单。高风险详情抽屉宽度 `min(510px,100vw)`、全高；新增 Agent 抽屉宽度 `min(640px,100vw)`，顶部从 App Bar 下方 `54px` 开始。抽屉背景 `#161f22`，左边框约 `#465257`，阴影 `-18px 0 40–44px rgba(0,0,0,.4)`。

抽屉头部高度：高风险 `55px`，新增 Agent `64px`；头部底边框 `#344145`。底部操作栏新增 Agent `66px`、高风险 `59px`，背景 `#182124`，上边框 `#344145`。主体可滚动，内边距 `17–20px`。

### 6.2 新增 Agent 抽屉内容

顶部工作区选择行约 `80px 1fr` 网格，字段高度 `36px`。内容标签页高度 `48px`，间距 `18px`，活动标签绿色下边框 `2px`。必须提供：

1. **新会话**：Agent 选项两列网格（每项约 `78px` 高），Codex/Claude/Pi/自定义命令标识；显示名称、审批策略和只读命令预览。
2. **恢复历史**：搜索标题/会话 ID/内容，按工作区列出原生会话，显示 Agent、session ID 摘要、分支和最近活动时间。
3. **迁移外部会话**：先列出检测到的 PID/cwd/session；说明迁移会在原终端正常停止后通过原生 resume 重开，不强行接管画面。匹配状态用绿色，无法匹配用琥珀；步骤提示使用绿色软背景。

### 6.3 高风险授权抽屉

详情顺序固定为：风险 kicker（红色）、标题、来源会话说明、命令代码块、四格影响事实、红色 warning box、底部取消/确认。命令块背景 `#0b1011`、圆角 `6px`、等宽字体；事实卡两列网格、圆角 `5px`。必须明确显示操作类型、影响文件数、目标位置、可恢复性和“自动学习：禁止”。递归删除、覆盖、提权、工作区外写入始终逐次确认。

## 7. 处理中心与授权展示

`approval-center-v1.html` 的三栏布局：侧栏 `215px`、队列 `355px`、详情剩余空间；队列头 `62px`，列表内边距 `9px`。队列项最小高度 `106px`，两列（8px severity + 内容），圆角 `7px`；活动项绿色边框，危险活动项红色边框。命令摘要使用 `9px` 等宽字体，元数据使用 `9px muted`，用中点分隔。

详情主体最大宽度 `820px`，居中，内边距 `24px`。标题约 `20px`；命令卡 `15px` 内边距；事实四列网格（窄屏两列）；原因说明使用左侧 `3px` 色条和圆角 `4px`。批准历史按 `92px 1fr auto` 三列，每行 `34px`，顶部边框分隔。

低风险可在详情底部直接“批准这一次/拒绝”。第三次批准后显示绿色学习卡，预览允许模式、生效范围、限制、来源 Agent，并提供“仍然每次询问/以后自动批准”。成功卡明确说明规则已加入授权列表及可撤销位置。高风险不显示学习选项，只显示查看文件/确认删除。异常恢复项显示错误原文、退出类型、恢复次数 `n/上限`、正常完成是否误判、当前状态和“再次恢复”。

总览内嵌审批使用卡片底部 inline request：低风险可直接批准，批准后替换为绿色成功条；高风险只显示“查看并处理”并打开抽屉。通知按钮可显示待处理徽标；处理中心聚合授权、异常、恢复失败和完成事件。

## 8. 审计和事件展示扩展

审计页沿用三栏/详情模式：左侧按工作区和日期筛选，中间事件列表，右侧显示事件详情。事件行至少展示时间、Agent、会话 ID 摘要、事件类型、状态、命令/目标摘要和决策来源（用户批准、自动规则、系统恢复、用户停止）。自动批准必须记录完整的规则 ID、工具名称、规范化命令/路径、风险分类和命中原因；不能只记录“用户批准了工具”。

审计详情可复用处理中心的命令卡、事实卡和历史行，危险操作显示不可恢复提示。筛选、复制和导出按钮使用普通图标/紧凑按钮；长命令折行。空状态只给出简短下一步，不创建大型说明卡。

## 9. 架构说明页与缺失页面扩展原则

架构页采用浅色双栏：顶部 `58px` 深色栏并带 `3px` 绿色底线；正文左侧图表（最小 `620px`）、右侧详情 `300–390px`，内边距 `24px`。模块卡最小高 `90px`、圆角 `7px`；活动模块绿色 `2px` 边框；层标题用 uppercase 小字和横线；流程带为浅灰背景、圆角 `6px`。这是阅读/设计审查页，不与暗色运行工作台混用。

`waiting-after-session-design.html` 只有居中等待文案（最小高度约 `60vh`），作为过渡/加载状态；实际产品应使用暗色工作台背景和 `muted` 文案，并在等待超过短时阈值后提供重试/返回动作。

缺失页面（设置、历史详情、审计、Agent 配置等）遵循：

- 复用暗色令牌、54px App Bar、215px Rail、46px Section Bar 和右侧抽屉模式。
- 优先使用列表、表格、详情分栏，不使用卡片套卡片或居中大表单。
- 每个状态同时给出文本、颜色和可执行动作；危险动作必须有明确影响和不可逆性。
- 新能力先在结构化事件/API 中建模，再由 UI 渲染；终端屏幕文字只能作为降级提示，不能作为自动批准/恢复的唯一依据。
- 2–6 个 Agent 时保证卡片可扫描；超过可见数量提供筛选/滚动，不把多个完整 UI 并排塞进一个屏幕。
- 响应式断点参考 `980/850px` 收窄侧栏和详情，`760/680/650px` 单列；桌面密度优先，移动端保证内容不溢出。

## 10. 实现检查清单

- [ ] 颜色来自本文档令牌，无新增竞品色或渐变。
- [ ] App Bar/Section Bar/Rail/卡片尺寸符合固定值，终端网格间距为 `8px`。
- [ ] 主操作、图标操作、危险操作的按钮语义和状态样式正确，图标按钮有 tooltip/aria-label。
- [ ] 终端使用等宽字体，长路径/命令不会撑破布局，放大不重建 PTY。
- [ ] 授权详情包含命令、cwd/目标、风险、影响范围、可恢复性、自动学习边界和来源会话。
- [ ] 审计事件包含工具名称/命令/路径/规则命中原因，而不是只有泛化文案。
- [ ] 正常结束、用户停止、明确异常断开在视觉和状态机上可区分；正常结束不自动 Continue。
- [ ] 新增/恢复/迁移入口使用右侧抽屉；高风险确认使用二次明确动作。
